E-Commerce Retail Analytics: Pricing & Inventory Strategy

This project focuses on analyzing e-commerce catalog data to uncover insights into pricing strategies, inventory distribution, and revenue optimization opportunities. Using web-scraped data, the project applies data analysis, visualization, and machine learning to identify patterns and support data-driven decision-making.

🚀 Project Overview
Scraped 1,000+ product records from an online book catalog using Python
Cleaned and transformed raw data for analysis
Performed Exploratory Data Analysis (EDA) to identify trends in price, ratings, and stock
Built a Random Forest Regression model to predict product pricing
Created an interactive Power BI dashboard for business insights

🛠️ Tech Stack
Python (Pandas, NumPy, BeautifulSoup, Scikit-learn)
Data Visualization (Matplotlib, Seaborn)
Machine Learning (Random Forest Regressor)
Power BI (Dashboard & reporting)

📌 Key Features
Web scraping from multiple catalog pages
Data cleaning (missing values, duplicates, formatting fixes)
Feature engineering (price bands, stock status, rating metrics)
Trend analysis (Price vs Rating, Stock vs Price Band)
Predictive modeling for pricing
Interactive dashboard for decision-makers

📈 Key Insights
Identified pricing concentration across budget, standard, and premium segments
Detected low-stock high-demand products
Found correlations between ratings and pricing patterns
Highlighted potential underpriced premium inventory

💡 Business Recommendations
Implement real-time inventory monitoring
Optimize pricing using price band segmentation
Leverage ML model for predictive pricing of new products
Use dashboards for continuous business tracking

📂 Dataset
Source: Custom web scraping (books.toscrape.com)
Size: ~1,000 records
Features: Title, Price, Rating, Stock Quantity
